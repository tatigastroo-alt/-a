# Практика — кейс-задачи 3 и 4

Файлы:
- `case3.py` — сумма отрицательных элементов между максимумом и минимумом массива.
- `case4.py` — максимальная сила драконьей стаи при ограничении не более 7 голов у одного дракона.

Запуск:
```bash
python case3.py
python case4.py
```

Для GitHub:
1. Создать новый репозиторий.
2. Добавить эти два файла и README.
3. Выполнить `git add .`, `git commit -m "Кейс-задачи учебной практики"`, `git push`.
